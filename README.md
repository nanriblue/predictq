# PredictQ

> 다음 모바일 기사뷰 하단에서 **"이 이슈는 앞으로 어떻게 될까?"** 를 확률형 예측 카드로 이어주는 **기사 기반 예측 리서치 Agent** (AI Agent 공모전 출품 목업)

## 한 줄 소개

이미 뉴스를 읽고 있는 맥락 위에서, 기사의 다음 궁금증을 **예측 질문**으로 바꾸고 공개 데이터 기반의 **가능성·근거·변수·반대 근거**를 계속 업데이트해주는 에이전트입니다. 거래/베팅이 아니라 **정보형 예측 리포트**라는 점이 차별점입니다.

## 데모

- **라이브 링크**: https://nanriblue.github.io/predictq/
- 상단 탭에서 **경제 / 스포츠 / 시사·법적** 3개 예시 기사를 전환하며 예측 카드를 체험할 수 있습니다.

## 핵심 화면 구성 (예측 카드)

| 요소 | 설명 |
|------|------|
| 예측 질문 | 기사 내용을 "앞으로 어떻게 될까?" 형태의 질문으로 변환 |
| 가능성(%) | 게이지로 시각화. 60%↑ 초록 / 45~59% 주황 / 45%↓ 회색 |
| 현재 공개 정보 기준 · 업데이트 시각 | 단정 방지 + 신선도 표시 |
| 📈 근거 / 🎯 핵심 변수 | 확률의 배경과 결과를 가를 변수 |
| ↔ 반대 근거 | 균형을 위한 반대 시각 (과신 방지) |
| 예측 업데이트 로그 | 확률이 시간에 따라 어떻게 변했는지 추이 |
| CTA | "예측 계속 받기", "업데이트 알림", "관련 함께 보기" |

### 민감 이슈 안전장치

시사·법적 기사는 `sensitive` 로 분류되어 **승소/패소 단정 금지**, **"법률 자문이 아닌 쟁점 분석"**, **"재판부 판단에 따라 달라질 수 있음"** 디스클레이머를 항상 함께 노출합니다.

## 기술 스택

- 순수 정적 **HTML / CSS / JavaScript** (빌드·의존성 없음)
- GitHub Pages 호스팅

## 실행 방법

```bash
# 저장소를 받은 뒤, 폴더에서 정적 서버 실행
python3 -m http.server 4173
# 브라우저에서 http://localhost:4173 접속
```

> 실제 API 없이 **더미 데이터**로 동작하는 목업입니다. 수치·뉴스는 예시이며 투자·법률 자문이 아닙니다.

## 폴더 구조

```
predictq/
├── index.html   # 화면 골격 (모바일 프레임 + 예시 전환 탭)
├── styles.css   # 전체 스타일
├── data.js      # 예시 기사 3종 + 예측 카드 데이터
├── app.js       # 데이터 → 화면 렌더링 로직
└── README.md
```

## 향후 확장 (기획 메모)

- 알림 / 구독 / MY / 검색 / 버티컬로 이어지는 연결고리
- 개인화: 관심 종목·선수·이슈를 md 형태로 기록하며 점점 더 잘 이해
- 예측 적중 이력 공개로 신뢰도 축적 (Metaculus식 트랙 레코드)
